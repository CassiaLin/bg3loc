# 盲翻優先重譯模式 (Blind-First Mode)

[English](blind-first.md)

這是專為「完全重新翻譯」專案設計的特殊模式。

**問題所在**：當翻譯人員看到舊的官方翻譯時，他們往往只會稍微修改它，而不是寫出一個全新且自然的翻譯。這被稱為「錨定效應」。在測試 200,000 行文字的記錄中，如果提供舊文字給 AI，它只會更改其中的 20,000 行！

## 運作方式

### 第一階段：盲翻草稿 (Pass 1: Blind Draft)
在第一步中，翻譯人員將**只會**看到英文原文、遊戲情境、術語表和受保護的佔位符號。

舊的翻譯會從檔案中**完全移除**（而不只是隱藏在某個欄位中）。翻譯人員必須完全從頭開始填寫 `IndependentTargetText`（獨立目標文字）。此階段需要 100% 完成！

### 第二階段：品質保證與比較 (Pass 2: QA Comparison)
在第一階段完全結束後，舊的翻譯和其他參考語言才會終於顯示出來。翻譯人員可以將他們的新作品與舊版本進行比較，以潤飾並修正任何錯誤。

## 技術細節

* **ProtectedTokens（受保護的代碼）**：這些是特殊的遊戲代碼，例如 `{SpeakerName}` 或 `%s`。它們**必須**保持原樣，這樣《柏德之門 3》才不會出錯。處理流程會自動為您提取並追蹤這些代碼。
* 預設情況下，現有的原始翻譯僅被視為參考資料，而不是最終權威。只有在有人明確標記 `ApprovedAuthority = true` 的情況下，它才會成為權威。
