# Basic Translation Mode

[繁體中文（台灣）](basic.zh-TW.md)

This is the simplest way to translate the game. It creates a spreadsheet that is easy to read.

You will see the original English text on one side, the existing translation on the other, and a blank column for your new translation. 

## What You Will See

Here are the details you can look at (these cannot be changed):
* **ContentUid**: A permanent ID number for each line of game text.
* The original English source text.
* The existing translation (if there is one).
* Game version numbers and presence status (if the text is currently in the game).

## What You Can Edit

You can type in these columns:
* **TranslatedTargetText**: Your new translation!
* **TranslationStatus**: Keep track of whether it is a draft, finished, or needs review.
* **TranslatorNotes**: Write down any thoughts or questions.
* **TranslatorName**: Put your name or nickname here.

## When to Use This

This mode is best for:
* Quick fixes to spelling or grammar.
* Starting a brand new translation.
* Small community mods where you just want to change a few lines.

⚠️ **Note**: This mode does NOT tell you who is speaking or which quest the text belongs to. For that, use [Context Mode](context.md).
