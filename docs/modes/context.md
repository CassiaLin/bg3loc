# Context Translation Mode

[繁體中文（台灣）](context.zh-TW.md)

This mode is just like the [Basic Mode](basic.md), but it gives you extra game information to help you translate better.

You will see exactly who is speaking (for example, Astarion or Gale). You will also see which quest the text belongs to, and what was said right before and after.

## Why This Helps

English words can be confusing! Words like "Fine!", "Fire!", or "Turn" have different meanings depending on what is happening. 

Having the context prevents mistranslations because you know exactly what is going on in the game.

## Important Details

* 🔒 **Locked Evidence**: The context fields (like speaker and quest names) are locked. Translators cannot edit them, so the information stays accurate.
* 💡 **Tip**: Generic buttons like "OK" or "Cancel" will usually have empty context fields. That is completely normal!
* This mode works independently and does not rely on reference languages from other countries.
