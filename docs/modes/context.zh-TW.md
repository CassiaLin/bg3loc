# 情境翻譯模式 (Context Mode)

[English](context.md)

此模式就像[基礎翻譯模式](basic.zh-TW.md)一樣，但它會提供您額外的遊戲資訊，幫助您翻譯得更好。

您會準確看到是誰在說話（例如：阿斯代倫或蓋爾）。您還會看到文字屬於哪個任務，以及前後說了什麼。

## 為什麼這有幫助

英文單字有時會令人困惑！像 "Fine!"（很好／罰款）、"Fire!"（開火／火）或 "Turn"（轉動／回合）這樣的字，會根據發生的情況有不同的含義。

擁有情境資訊可以防止誤譯，因為您完全了解遊戲中正在發生什麼事。

## 重要細節

* 🔒 **鎖定的證據**：情境欄位（如說話者和任務名稱）是鎖定的。翻譯人員無法編輯它們，以確保資訊的準確性。
* 💡 **提示**：像「確定」或「取消」這類通用按鈕通常會有空白的情境欄位。這是完全正常的！
* 此模式獨立運作，不依賴其他國家/地區的參考語言。
