# 基礎翻譯模式 (Basic Mode)

[English](basic.md)

這是翻譯遊戲最簡單的方法。它會建立一個易於閱讀的試算表。

您會在一側看到原始的英文文字，另一側則是現有的翻譯，並且有一個空白欄位讓您填寫新的翻譯。

## 您會看到的內容

以下是您可以查看的詳細資訊（這些無法更改）：
* **ContentUid**：每筆遊戲文字的身分證號碼。
* 原始的英文文字。
* 現有的翻譯（如果有的話）。
* 遊戲版本號碼與存在狀態（該文字目前是否在遊戲中）。

## 您可以編輯的內容

您可以在這些欄位中輸入：
* **TranslatedTargetText**：您的新翻譯！
* **TranslationStatus**：記錄翻譯狀態（例如：草稿、完成、需要檢查）。
* **TranslatorNotes**：寫下任何想法或問題。
* **TranslatorName**：在這裡填寫您的名字或暱稱。

## 何時使用此模式

此模式最適合：
* 快速修正錯別字或文法。
* 開始一個全新的翻譯。
* 只需要更改幾行文字的小型社群模組。

⚠️ **注意**：此模式不會告訴您說話者是誰，或是文字屬於哪個任務。如需這些資訊，請使用[情境模式 (Context Mode)](context.zh-TW.md)。
