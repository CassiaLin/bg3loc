# bg3loc validate

[English](validate.md)

**`bg3loc validate`** 就像是你的品管檢驗員。它會檢查你交回來的翻譯試算表，確保它們不會讓遊戲崩潰。

## 它的功用

- **身分檢查：** 每一行都必須對應到真實的 `ContentUid`（每筆遊戲文字的身分證號碼）。不允許有重複的行數。
- **防篡改保護：** 如果有人偷改了英文原文或語言名稱，它會立刻報錯。
- **保護語法檢查：** 遊戲的特殊代碼（例如 `{SpeakerName}`）必須原封不動地保留。如果缺少代碼，或者擅自加入了未授權的代碼，都會引發錯誤。損壞的格式（如壞掉的 `<LSTag>` 標籤）也會報錯。
- **盲翻優先覆蓋率：** 如果你使用盲翻優先模式，所有規定要翻的行數都必須填寫。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc validate
```

## 嚴格模式

預設情況下，工具會以**嚴格模式**執行。這代表只要有任何一個錯誤，就會完全阻擋你進行下一步。
如果你關閉嚴格模式，它會接受正確的行數，並把錯誤的行數另外挑出來。

💡 **提示：** 沒翻譯到的行數只會被當作進度資訊來計算。它們不會產生個別的警告錯誤。

⚠️ **警告：** 這個工具「不會」評判你的文學造詣或文法。它只在乎檔案在技術上能不能正常運作。

## 輸出結果

它會把所有東西放在 `workspace/validate/` 資料夾中，並清楚分開被接受的紀錄、被拒絕的紀錄，以及錯誤報告。
