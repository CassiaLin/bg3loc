# bg3loc install

[English](install.md)

**`bg3loc install`** 是唯一一個「真正會」把檔案寫入你遊戲資料夾的指令。

💡 **提示：** 永遠記得先執行 `bg3loc install --dry-run`！這能讓你在不實際更改任何東西的情況下，預覽會發生什麼事。

## 它的功用

- **安裝前檢查：** 它會仔細檢查你的遊戲身分、版本號，並驗證檔案的雜湊值，確保一切吻合。
- **強制備份：** 在將任何東西寫入你的遊戲之前，它永遠都會先建立一個帶有時間標記的備份。
- **安全替換：** 它會先寫入一個暫存檔，確認完美無誤後，瞬間切換過去，然後再次檢查。
- **自動還原：** 如果最後的檢查失敗，它會立刻將你的遊戲還原到備份狀態。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc install
```

如果你需要手動復原安裝，你可以使用：

```bash
bg3loc install --rollback <manifest>
```

## 安全保證

- **沒有 `--force` 強制執行：** 如果你的遊戲在上次掃描後有更新過，工具會立刻停止，並要求你重新掃描。
- **檔案鎖定：** 在安裝前請務必關閉遊戲，尤其是在 Windows 上！
- **支援平台：** 安全處理 Windows（Steam 路徑）、Linux/Proton（區分大小寫的路徑）和 macOS（原生套件路徑）上的檔案位置。
