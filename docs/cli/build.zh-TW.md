# bg3loc build

[English](build.md)

**`bg3loc build`** 會建立讓翻譯人員實際工作的試算表檔案。

因為遊戲的文字量非常龐大（超過 23 萬行！），它會把文字切分成小批次。預設是每個檔案 1500 行，這樣你的 Excel 就不會卡死。

## 它的功用

- 提供三種模式供翻譯人員選擇：基本、上下文，或是盲翻優先模式。
- 尋找**受保護的標記 (ProtectedTokens)**：這些是遊戲使用的特殊代碼，例如 `{SpeakerName}` 或 `%s`。翻譯人員「必須」在翻譯中保留這些代碼。
- 建立一個不可篡改的基準線。這是一個被鎖定、安全的原始英文文字紀錄，防止任何人偷偷竄改原文。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc build
```

⚠️ **警告：** 這個指令「不會」幫你翻譯任何東西，也不會呼叫任何 AI 工具。它只負責準備檔案。

## 輸出結果

它可以輸出 Excel (`.xlsx`)、CSV (`.csv`) 或 JSON Lines (`.jsonl`) 格式的檔案。所有的檔案都會放在 `workspace/build/` 資料夾中。
