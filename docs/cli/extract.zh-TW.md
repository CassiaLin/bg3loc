# bg3loc extract

[English](extract.md)

**`bg3loc extract`** 會解開遊戲的語言檔，讓你可以閱讀裡面的文字。

## 它的功用

- 選擇來源語言（例如英文）和目標語言（例如繁體中文）。
- 你也可以選擇加入其他的參考語言。
- 將無法直接閱讀的二進位遊戲檔案（`.loca`）轉換成可讀的純文字。
- 使用 `ContentUid`（每筆遊戲文字的身分證號碼）來對齊句子。它會保留所有的內容，即使某個語言缺少了一行。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc extract
```

## 雙向轉換驗證

它會來回轉換文字，證明沒有任何資料遺失。這能保證你的遊戲檔案不會因此損壞。

## 檔案優先順序

如果遊戲有更新檔，它會自動使用最新版本的文字（主程式 → 更新檔 → 熱修復）。它會從壓縮包裝檔裡，為每種語言精準挑選出唯一的一個語言檔（`.loca`）。

⚠️ **警告：** 這個工具「不會」評判翻譯的品質，它只負責取出文字。

## 輸出結果

它會建立一個 `workspace/extract/` 資料夾，裡面有摘要檔案、本地化文字和對齊好的資料。
