# bg3loc scan

[English](scan.md)

**`bg3loc scan`** 是整個處理流程的第一步。它就像一個斥候，會在你的電腦裡尋找《柏德之門 3》安裝在哪裡。

這個指令完全是唯讀的，代表它絕對不會更改或弄壞你的遊戲檔案。

## 它的功用

1. 尋找你的 Steam 安裝位置。
2. 找到《柏德之門 3》的遊戲路徑。
3. 找到遊戲的資料夾 (Data)。
4. 找到語言包（遊戲的壓縮包裝檔，也就是 `.pak` 檔）。
5. 在裡面找到語言檔（`.loca`）。
6. 列出所有可用的語言。

完成後，它會儲存一個名為 `workspace/scan-manifest.json` 的摘要檔案。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc scan
```

💡 **提示：** 它是自動發現語言的。沒有寫死在程式裡的清單！只要你有安裝的都會被找出來。

### 額外選項

- `--game-dir`：直接告訴它遊戲在哪裡。
- `--steam-library`：直接告訴它 Steam 收藏庫在哪裡。
- `--platform`：告訴它你的作業系統。
- `--backend`：選擇後端工具。

## 特殊功能

- **重複處理：** 如果有兩個包裝檔都宣稱自己是同一種語言，它會標記為「不明確」。
- **支援平台：** 支援 Windows（Steam 收藏庫）、Linux/Proton（直接的 Steam 路徑）和 macOS（原生 Steam）。
- **安全性：** 為了安全起見，會忽略捷徑（符號連結）。

⚠️ **警告：** 這個步驟需要透過 `BG3LOC_DIVINE_EXE` 來設定第三方解包工具（LSLib 或 `Divine.exe`）。

## 錯誤代碼說明

- `0`：成功
- `2`：找不到遊戲
- `3`：遺失資料夾
- `4`：找不到遊戲語言
- `5`：語言不明確（有重複）
- `6`：後端工具無法使用
- `7`：探索錯誤
