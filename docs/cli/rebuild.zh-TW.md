# bg3loc rebuild

[English](rebuild.md)

**`bg3loc rebuild`** 會將你的翻譯重新組合起來。它「只」會採用上一步驗證通過的紀錄，並將它們與原始的遊戲文字合併。

## 它的功用

- **安全合併：** 它會拿包含超過 23 萬行的完整遊戲文字作為基底，而且「只」替換你翻譯的那些行。沒有動到的行數會非常安全地保持原樣。
- **基底優先：** 它「絕對不會」只用你翻譯的那幾行從頭建立一個全新的語言檔。它永遠都會使用完整的遊戲檔案作為基礎。
- **雙重檢查：** 重新組合後，它會再次讀取新檔案，驗證所有內容都完美吻合（我們稱之為語義來回測試）。
- **智慧打包：** 根據你的遊戲配置，它會自動決定只要產生遊戲語言檔（`.loca`），還是要幫你打包成壓縮包裝檔（`.pak`）。

## 如何使用

只要打開命令列並輸入：

```bash
bg3loc rebuild
```

## 缺失翻譯處理原則

- 如果英文原文有某一句話，但你的目標語言原本沒有，而你提供了翻譯：它會為你建立一個新條目！
- 如果你沒有提供翻譯：它會保持空白（它絕對不會無中生有）。
- 如果你的目標語言多出了一句話，但英文原文沒有：它會安全地保留那句話。

⚠️ **警告：** 被拒絕或未經驗證的行數「絕對不會」被寫入。這個指令也「還不會」把文字安裝到你的遊戲中。

## 輸出結果

它會把所有東西放在 `workspace/rebuild/` 資料夾中，包含最終的 `.loca` 或 `.pak` 檔案，以及驗證報告。
