# 工具如何重現遊戲資料

[English](overview.md)

這頁將解釋 `bg3loc` 工具是如何在幕後運作，直接從你自己的遊戲中提取資料的。

---

## 目的

我們工具的目的是讓任何擁有正版《柏德之門 3》的玩家，都能做到以下幾點：
1. 從自己的電腦遊戲檔案中，直接掃描並提取出文字以及故事語境。
2. 重新產生需要翻譯的特定文字群組，例如：環境語音 (Bark)、任務、對話以及介面文字。
3. 安全地匯入你的翻譯，而且我們完全不需要在網路上存放或分享官方的遊戲文字。

---

## 架構設計

我們的工具就像是你與遊戲之間的橋樑。以下是處理流程的結構：

```text
+------------------------------------+
|    Portable Core (bg3loc)          |
|  - 建立檔案、檢查規則              |
+-----------------+------------------+
                  |
+-----------------v------------------+
|    BG3 Game Adapter                |
|  - 尋找 Steam、解包檔案            |
+-----------------+------------------+
                  |
+-----------------v------------------+
|    Research Reproduction Layer     |
|  - 連結屬性與規則                  |
|  - 判斷哪個更新檔才是最新的        |
|  - 理解對話的語境                  |
|  - 整理任務資訊                    |
|  - 比較不同語言                    |
|  - 映射介面與技能文字              |
|  - 處理殘留的故事文字              |
+------------------------------------+
```

這套工具只會在文字上加上有用的語境提示。它絕對不會破壞或改變遊戲讀取檔案的基礎規則！
