# 保持遊戲文字隱私

[English](corpus-boundary.md)

為了尊重遊戲開發者的版權，同時又能打造出優秀的翻譯工具，`bg3loc` 嚴格遵守了放在網路上分享的界線。

---

## 我們公開分享的內容

我們只分享讓工具運作的程式碼，不分享遊戲本身。

1. **程式碼：** 用來讀取和整理檔案的 Python 腳本。
2. **規則：** 規範試算表和文字檔格式的藍圖。
3. **身分證號碼：** 每筆遊戲文字的身分證號碼（例如 `ContentUid`）。這裡面不包含任何遊戲裡的實際文字。
4. **假測試資料：** 為了確保程式碼能運作而隨便捏造的句子。
5. **指南：** 像這樣解釋如何使用工具的說明手冊。

---

## 我們絕對不公開分享的內容

⚠️ **警告：** 我們嚴格禁止上傳這些檔案！

1. **官方遊戲文字：** 遊戲中任何英文或其他語言的實際句子。
2. **遊戲檔案：** 遊戲的壓縮包裝檔（`.pak`）或語言檔（`.loca`）。
3. **別人的工具：** 第三方解包工具（`Divine.exe`）。你必須自己下載！
4. **完成的翻譯：** 玩家做好的最終完成版翻譯檔。
