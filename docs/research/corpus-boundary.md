# Keeping Game Text Private

[繁體中文（台灣）](corpus-boundary.zh-TW.md)

To respect the game developers' copyrights while still making a great translation tool, `bg3loc` follows strict rules about what goes on the internet.

---

## What We Share Publicly

We only share the code that makes the tool work, not the game itself.

1. **Code:** The Python scripts that read and organize the files.
2. **Rules:** The blueprints for how our spreadsheets and text files should look.
3. **ID Numbers:** The permanent ID numbers for each line of game text (like `ContentUid`). These don't contain any actual words from the game.
4. **Fake Test Data:** Made-up sentences we use to make sure our code works.
5. **Guides:** Manuals like this one explaining how to use the tool.

---

## What We NEVER Share Publicly

⚠️ **Warning:** We strictly forbid uploading these files!

1. **Official Game Texts:** Any actual sentences in English or other languages from the game.
2. **Game Files:** The game's compressed package files (`.pak`) or language files (`.loca`).
3. **Other People's Tools:** The third-party unpacking tool (`Divine.exe`). You have to download it yourself!
4. **Finished Translations:** The final completed translation files created by users.
