# Content UIDs

[繁體中文（台灣）](content-uid.zh-TW.md)

What is a ContentUid? It is a permanent ID for each line of game text. Think of it like a social security number or identity card for words—it never changes, no matter how you sort, split, or reorganize the files. 

This permanent ID is what connects the original English text to its translation across all languages in the game. 

⚠️ **What ContentUids are NOT**
ContentUids are not row numbers, file names, or batch IDs. Those are just physical locations that can change when you move things around. 

💡 **The Golden Rule**
When we align or join translations between different languages, we always use the ContentUid to match them up exactly.
