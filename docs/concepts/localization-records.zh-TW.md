# 翻譯紀錄卡 (Localization Records)

[English](localization-records.md)

在進行任何翻譯工作之前，bg3loc 會將遊戲文字轉換為標準化的「索引卡」，我們稱之為**紀錄 (records)**。

每張紀錄卡包含：
* **ContentUid**: 每行遊戲文字的固定身分證號碼。
* **語言 (Language)**: 文字的語言。
* **文字 (Text)**: 實際的遊戲文字。
* **版本 (Version)**: 文字的版本號碼。
* **來源檔案 (Source File)**: 文字來自哪裡。

💡 **完整保留 (Full Outer Join)**
當比較不同語言時，我們會保留所有內容。如果英文有一行中文沒有的字，或者反過來，兩者都會被保留下來。沒有任何東西會被丟棄！

⚠️ **雙向轉換檢查 (Round-Trip Check)**
為了確保沒有遺漏任何內容，bg3loc 會在不同格式之間來回轉換文字。如果最終結果與一開始完全一致，我們就知道我們的翻譯是安全的。
