# 運作原理 (Architecture)

[English](architecture.md)

bg3loc 工具由五個不同的部分組成，它們互相合作來幫助你翻譯《柏德之門 3》。你可以把它們想像成蛋糕的不同夾層！

## 五個夾層

1. **Portable Core（核心工具）：** 這是主要的大腦。它負責處理翻譯規則、追蹤文字編號，並檢查有沒有錯誤。它不會直接去碰遊戲檔案。
2. **BG3 Game Adapter（遊戲適配器）：** 這部分知道所有關於《柏德之門 3》的特定規則。它了解遊戲是如何整理檔案的、對話中是誰在說話，以及哪一個遊戲更新檔才是最新的。
3. **Version Discovery（版本偵測）：** 每當遊戲更新時，這部分會檢查你安裝的遊戲並重新計算新內容。它會找出有哪些語言檔，以及目前的文字編號是什麼。
4. **Platform Adapter（平台適配器）：** 這部分知道遊戲安裝在你的電腦的哪個地方。不管是 Windows、Linux 還是 macOS，它都能自動搞定！
5. **Archive Backend（後端工具）：** 這部分負責處理遊戲的壓縮包裝檔（`.pak`）和語言檔（`.loca`）。它會使用第三方解包工具（例如 `Divine.exe`）來打開它們，並且再把把它們打包回去。

## 最重要的一條規則

**ContentUid** 是每筆遊戲文字的身分證號碼。

當我們在追蹤文字時，這個身分證號碼是**唯一**重要的東西。行號、檔案名稱或批次號碼都是不可靠的。ContentUid 才是一句話真正的身分證明！
