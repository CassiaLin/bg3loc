# BG3Loc v1.0.0

BG3Loc v1.0.0 is the first stable release of the reusable Baldur's Gate 3 localization pipeline. It supports arbitrary source and target locales discovered dynamically from a user's own game installation without hard-coded language assumptions.

BG3Loc v1.0.0 是可重複使用的《柏德之門 3》在地化 pipeline 第一個正式版本。它支援從使用者自身遊戲安裝中動態偵測任意來源與目標語言，無寫死之語言假設。

## Highlights / 重點功能

- Complete `scan → extract → build → validate → rebuild → install` workflow.  
  完整的 `scan → extract → build → validate → rebuild → install` 工作流程。
- Basic, Context, and Blind-first translation modes.  
  提供 Basic、Context 與 Blind-first 翻譯模式。
- CSV and XLSX translation materials with immutable-baseline and protected-token validation.  
  提供 CSV、XLSX 翻譯素材，以及 immutable baseline 與 protected-token 驗證。
- Rebuild semantic verification and archive structure integrity validation.  
  重建後之語意驗證與 archive 結構完整性驗證。
- Safe install dry-run, verified backup, post-write verification, and verified rollback.  
  提供安全的安裝預演、經驗證之備份、寫入後驗證與完整回滾。
- PEP 639 modern packaging metadata (`License-Expression: MIT`).  
  採用 PEP 639 現代打包詮釋資料規格（`License-Expression: MIT`）。

## Validated platform / 已驗證平台

Windows 11 is the Tier 1 validated platform. The complete Windows workflow has passed real-hardware acceptance using Python 3.12, LSLib 1.20.4, and a Steam BG3 installation. The package contract requires Python 3.11 or newer; Python 3.12 and LSLib 1.20.4 are validated baselines, not exclusive requirements.

Windows 11 是目前的 Tier 1 已驗證平台。完整 Windows 工作流程已使用 Python 3.12、LSLib 1.20.4 與 Steam BG3 在真實硬體上通過驗收。套件規格要求 Python 3.11 以上版本；Python 3.12 與 LSLib 1.20.4 是已驗證基準，而非唯一可用版本。

- **English → ChineseTraditional**: Full real-install acceptance with byte-identical backup restoration and verified rollback.  
  **English → ChineseTraditional**：完成真實安裝驗收，包含位元組完全一致的備份復原與經驗證回滾。

## Installation / 安裝

Install from a downloaded GitHub Release wheel:

```powershell
python -m pip install .\bg3loc-1.0.0-py3-none-any.whl
```

Or install from GitHub source:

```powershell
git clone https://github.com/CassiaLin/bg3loc.git
cd bg3loc
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install .
bg3loc --help
```

可從下載的 GitHub Release wheel 安裝，亦可從 GitHub source 安裝。

## LSLib prerequisite

BG3Loc does not bundle LSLib. Download it separately from the [Norbyte/lslib upstream releases](https://github.com/Norbyte/lslib/releases). LSLib 1.20.4 is the validated Windows backend baseline. Configure the extracted `Packed\Tools\Divine.exe` through `BG3LOC_DIVINE_EXE` as described in the [archive backend guide](../concepts/archive-backends.md).

BG3Loc 不內含 LSLib。請另行從 [Norbyte/lslib upstream releases](https://github.com/Norbyte/lslib/releases) 下載。LSLib 1.20.4 是 Windows 已驗證 backend 基準；請依 [archive backend 說明](../concepts/archive-backends.md) 透過 `BG3LOC_DIVINE_EXE` 指定解壓縮後的 `Packed\Tools\Divine.exe`。

## Safety / 安全性

- Commands before `install` (`scan`, `extract`, `build`, `validate`, `rebuild`) never modify the game installation.  
  `install` 之前的指令（`scan`、`extract`、`build`、`validate`、`rebuild`）絕不修改遊戲安裝目錄。
- Always run `bg3loc install --dry-run` before every real installation.  
  每次真實安裝前都應先執行 `bg3loc install --dry-run`。
- Real installation verifies build and baseline identity, creates a verified backup, verifies written artifacts, and records rollback metadata.  
  真實安裝會驗證 build 與 baseline 身份、建立經驗證備份、核對寫入 artifact，並記錄 rollback metadata。
- Missing archive backends fail closed with an actionable error message rather than producing uninspected manifests.  
  找不到 archive backend 時會以具體可操作之錯誤訊息 fail closed，不會產生未經檢測之 manifest。

## Data and copyright boundary / 資料與著作權邊界

BG3Loc does not ship Larian localization data or translated game text. Users extract localization resources from their own Baldur's Gate 3 installation. Release packages contain only BG3Loc code, schemas, and documentation. LSLib is obtained separately from its upstream project.

BG3Loc 不散布 Larian 在地化資料或遊戲翻譯文本。使用者需從自己的《柏德之門 3》安裝中提取語言資源。發布套件只包含 BG3Loc 程式碼、schema 與文件；LSLib 必須另行自其 upstream project 取得。
