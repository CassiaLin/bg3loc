# BG3Loc v1.0.0-rc1

> This is a release candidate, not the final v1.0.0 release.
> 這是發布候選版（Release Candidate），尚非最終 v1.0.0 正式版。

BG3Loc v1.0.0-rc1 is the first release candidate for a reusable Baldur's Gate 3 localization pipeline. It supports arbitrary source and target locales discovered from a user's own game installation.

BG3Loc v1.0.0-rc1 是第一個可重複使用的《柏德之門 3》在地化 pipeline 發布候選版，可使用從玩家自身遊戲安裝中偵測到的任意來源與目標語言。

## Highlights / 重點功能

- Complete `scan → extract → build → validate → rebuild → install` workflow.
  完整的 `scan → extract → build → validate → rebuild → install` 工作流程。
- Basic, Context, and Blind-first translation modes.
  提供 Basic、Context 與 Blind-first 翻譯模式。
- CSV and XLSX translation materials with immutable-baseline and protected-token validation.
  提供 CSV、XLSX 翻譯素材，以及 immutable baseline 與 protected-token 驗證。
- Safe install dry-run, backup, post-write verification, and rollback.
  提供安全的安裝預演、備份、寫入後驗證與回滾。

## Validated platform / 已驗證平台

Windows 11 is the Tier 1 validated platform. The complete Windows workflow has passed real-hardware acceptance using Python 3.12, LSLib 1.20.4, and a Steam BG3 installation. The package contract remains Python 3.11 or newer; Python 3.12 and LSLib 1.20.4 are validated baselines, not exclusive requirements.

Windows 11 是目前的 Tier 1 已驗證平台。完整 Windows 工作流程已使用 Python 3.12、LSLib 1.20.4 與 Steam BG3 在真實硬體上通過驗收。套件仍支援 Python 3.11 以上版本；Python 3.12 與 LSLib 1.20.4 是已驗證基準，而非唯一可用版本。

Linux/Proton and macOS remain unvalidated on real target platforms. The cross-platform architecture does not mean those platforms have completed acceptance.

Linux/Proton 與 macOS 尚未在真實目標平台完成驗證。跨平台架構不代表這些平台已通過驗收。

## Workflow / 工作流程

1. `bg3loc scan` discovers the game installation, archive backend, and available locales.
2. `bg3loc extract` extracts and normalizes selected source and target localization resources.
3. `bg3loc build` creates translation materials in Basic, Context, or Blind-first mode.
4. `bg3loc validate` checks identity, immutable fields, coverage, and protected syntax.
5. `bg3loc rebuild` merges accepted text and verifies semantic and archive integrity.
6. `bg3loc install` supports dry-run, verified backup, deployment, and rollback.

1. `bg3loc scan` 偵測遊戲安裝、archive backend 與可用語言。
2. `bg3loc extract` 提取並正規化所選來源與目標語言資源。
3. `bg3loc build` 建立 Basic、Context 或 Blind-first 翻譯素材。
4. `bg3loc validate` 驗證身份、不可變欄位、覆蓋率與受保護語法。
5. `bg3loc rebuild` 合併已接受譯文，並驗證語意與 archive 完整性。
6. `bg3loc install` 提供預演、經驗證的備份、部署與回滾。

## Safety / 安全性

- Commands before `install` do not modify the game installation.
  `install` 之前的指令不會修改遊戲安裝。
- Run `bg3loc install --dry-run` before every real installation.
  每次真實安裝前都應先執行 `bg3loc install --dry-run`。
- Real installation verifies the build and baseline, creates a backup, verifies the written artifact, and records rollback metadata.
  真實安裝會驗證 build 與 baseline、建立備份、核對寫入 artifact，並記錄 rollback metadata。
- Missing archive backends fail closed with an actionable error instead of producing a successful scan manifest.
  找不到 archive backend 時會以可操作的錯誤訊息 fail closed，不會產生看似成功的 scan manifest。

## Installation / 安裝

Install from GitHub source:

```powershell
git clone https://github.com/CassiaLin/bg3loc.git
cd bg3loc
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install .
bg3loc --help
```

After a wheel is attached to the GitHub release, it can be installed from the downloaded asset without assuming a PyPI publication:

```powershell
python -m pip install .\bg3loc-1.0.0rc1-py3-none-any.whl
```

可從 GitHub source 安裝。GitHub Release 附上 wheel 後，也可安裝已下載的 wheel asset；本候選版不假設 PyPI 已發布。

## LSLib

BG3Loc does not bundle LSLib. Download it separately from the [Norbyte/lslib upstream releases](https://github.com/Norbyte/lslib/releases). LSLib 1.20.4 is the validated Windows backend baseline. Configure the extracted `Packed\Tools\Divine.exe` through `BG3LOC_DIVINE_EXE` as described in the [archive backend guide](../concepts/archive-backends.md).

BG3Loc 不內含 LSLib。請另行從 [Norbyte/lslib upstream releases](https://github.com/Norbyte/lslib/releases) 下載。LSLib 1.20.4 是 Windows 已驗證 backend 基準；請依 [archive backend說明](../concepts/archive-backends.md) 透過 `BG3LOC_DIVINE_EXE` 指定解壓縮後的 `Packed\Tools\Divine.exe`。

## Data and copyright boundary / 資料與著作權邊界

BG3Loc does not ship Larian localization data or translated game text. Users extract localization resources from their own Baldur's Gate 3 installation. Release packages contain only BG3Loc code, schemas, and documentation. LSLib is obtained separately from its upstream project.

BG3Loc 不散布 Larian 在地化資料或遊戲翻譯文本。使用者需從自己的《柏德之門 3》安裝中提取語言資源。發布套件只包含 BG3Loc 程式碼、schema 與文件；LSLib 必須另行自其 upstream project 取得。

## Upgrade and release-candidate notice / 升級與候選版提醒

Release-candidate artifacts may be replaced after review. If source changes, discard older wheel and source-distribution artifacts and use packages rebuilt from the final reviewed commit. Review the changelog and rerun `scan` after game or tool updates before rebuilding or installing localization packages.

發布候選 artifact 可能在 review 後更新。若 source 有變更，請丟棄舊 wheel 與 source distribution，並使用從最終 review commit 重建的套件。遊戲或工具更新後，在 rebuild 或 install 前請先查看 changelog 並重新執行 `scan`。
