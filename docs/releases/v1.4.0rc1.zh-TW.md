# BG3Loc 1.4.0rc1 — 本機 RC 說明

[English](v1.4.0rc1.md)

**尚未正式發布。** 這是本機 RC 候選版，沒有正式 Tag、GitHub Release 或 PyPI 發布。版本與工程檢查不代表授權部署、修改遊戲或 Production Activation。操作請先閱讀 [Windows Basic 入門](../getting-started.zh-TW.md)。

## 首版範圍

Windows Basic 使用玩家自己安裝的 BG3，以及另行安裝的 LSLib／Divine。選擇少量實際 source UIDs，維持單一操作者及穩定的原始 Extract／baseline 路徑：

1. 安裝工具與後端，建立 Basic 專案並 Prepare 素材。
2. 手動或外部翻譯，回填原本產生的 XLSX／JSONL；保留 immutable source／identity 欄位及 runtime syntax。
3. Validate，重建 LOCA；依 target container 的需要產生 PAK。
4. 使用沒有 `--apply` 的 `workflow install` 做 fresh Dry-run；任何失敗都停止。

技術 QA 不能證明語意品質或遊戲可載入。Dry-run 只寫專案證據，不修改遊戲，也不授權 Apply／Rollback。低階 `install` 預設 apply，不能當作繞過受阻 workflow 的替代路徑。

## 納入的完整性成果

- A1：canonical locale roles、完整 source／material projection 檢查。
- A6：scan 與當前 source／target PAK freshness，包含 late changes 拒絕。
- A8：repack 完整 entry set、每個未替換 entry SHA、LOCA payload／語意及 atomic candidate publication。
- M2-B1/B2：prepare-time `basic-source-baseline/1` Receipt、確切 current validated snapshot、每次 fresh Dry-run、歷史成功與當前資格區分，以及 failed-output isolation。
- 保留 A2 Provider 錯誤隱私與 A5 Legacy Review／QA evidence 綁定。CI 使用完整 pytest；sdist 保留經審查的公開 synthetic fixtures。

套件／runtime 版本為 `1.4.0rc1`。新研究匯出 manifest 的 producer stamp 為 `bg3loc-1.4.0rc1`；request IDs、ordering、prompt bytes 與 request-package fingerprints 保留原契約。既有研究產物與歷史驗收紀錄不重寫。

## 相容性與復原

舊 Basic workspace 缺必要 Receipt 時 fail closed，不自動 backfill 或遷移 edited returns。先保留舊回填，對當前遊戲 fresh Scan／Extract／Prepare／Validate，再人工比對 UID／source／version，rebase 合適譯文。修改回填後須重新 Validate → Rebuild → Dry-run；歷史成果路徑不代表目前可安裝。

Workspace／DB schema、Stage 0 contracts、Receipt 版本、H0／HSE identity 與 Prompt 演算法不變。套件發布版本是不同的版本軸。

## 排除與延後能力

Production／自動 Provider、B1-02 activation、Legacy Production Finalize、進階 context/full research 不屬首版 Windows Basic 驗收。**A7 implementation 仍 DEFERRED，其 Legacy portability／concurrency 缺陷尚未修復。** B1-03 預設 OFF、production transport blocked；保留程式不代表 Activation 或一般 dialogue safety 通過。Linux／macOS Native、detached portability、多操作者與 whole-corpus throughput 未驗收。

## 剩餘發布門檻

- 四個 GitHub-hosted jobs（Windows／Ubuntu × Python 3.11／3.12）：實際執行並通過 declared gates 前維持 **NOT VERIFIED**。
- 在可使用 socket 的環境完成真正 HTTP demo。WinError 10013 是 **environment-blocked，不算 PASS**；demo 保留在完整 pytest。
- Windows 長路徑與 host symlink 限制仍須明列；短路徑 synthetic 結果不保證任意路徑。
- 三份 research BOM schema 有既有 `SchemaStore.load` 限制，仍完整封裝；Basic Receipt 不受影響，不宣稱進階研究驗收。
- Windows Native 真實安裝的唯讀驗收，以及另行明確授權的小範圍 game-load／Apply／Rollback、verified backups 與復原。
- 最終 source／artifact review 與獨立發布授權；本機 RC 不能直接宣告 Stable Release。

Release artifacts 不含真正 PAK／LOCA、專有文本、SQLite、憑證、hidden assignments 或 Divine binary。核對 candidate source 與 artifact SHA256，不只看版本字串。
