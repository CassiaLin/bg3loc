# BG3Loc v1.2.0

BG3Loc v1.2.0 adds a production-scale translation workflow for projects with tens or hundreds of thousands of localization records while preserving the existing v1.0/v1.1 localization and end-to-end workflow foundations.

BG3Loc v1.2.0 在既有 v1.0／v1.1 語言處理與端到端流程之上，加入可處理數萬到數十萬筆 localization record 的大型翻譯 production workflow。

## Highlights / 重點功能

- Deterministic functional classification with one primary production owner per `ContentUid`.
- Category-aware, reproducible batching that preserves related context without creating duplicate translation jobs.
- Durable SQLite-backed translation execution state with attempts, retries, leases, recovery, provider/model provenance, and invalidation.
- Provider-neutral execution with an OpenAI-compatible adapter.
- Automatic QA routing: `PASS`, `RETRY`, `REVIEW`, and `FAIL`.
- Provenance-bound human REVIEW resolution:
  - `ACCEPT` approves the exact current output.
  - `REVISE` writes a new output that must pass QA again.
- Production completion analysis and merge-ready export.
- Final merge bridge into the existing rebuild flow.
- Auditable unclassified resolution overlay with `assign`, `exclude`, and `pending`.
- Public large-scale production guide and example ruleset.
- Release packaging support for nested LSTP/research schemas.

## Large-scale workflow / 大型翻譯流程

The public production path is:

```text
research classify
→ research resolve-unclassified (when needed)
→ research batch
→ translation-state
→ qa
→ production status
→ production bridge
→ rebuild
→ install --dry-run
```

See `docs/lstp/large-scale-production-guide.md` for the full operator workflow.

## Compatibility / 相容性

v1.2.0 is a feature release over v1.1.0. Existing low-level Core commands and the v1.1 end-to-end workflow remain available.

The large-scale production workflow composes the accepted rebuild/install path rather than replacing it.

## Installation / 安裝

Install the GitHub Release wheel:

```powershell
python -m pip install .\bg3loc-1.2.0-py3-none-any.whl
```

BG3Loc requires Python 3.11 or newer. Python 3.12 is the validated Windows release baseline.

## LSLib prerequisite

BG3Loc does not bundle LSLib. LSLib remains a separately installed third-party prerequisite for archive operations.

Configure `Packed\Tools\Divine.exe` through `BG3LOC_DIVINE_EXE` as described in the archive backend documentation.

## Safety / 安全性

- Translation production state and QA work do not modify the game installation.
- `production bridge` only exports rows that satisfy the current merge-readiness contract.
- Human REVIEW approval is bound to the current QA identity and exact output; stale approval does not follow changed output.
- Human revision cannot bypass QA.
- Unclassified decisions are an auditable overlay and do not rewrite the original automatic classification ledger.
- Real installation remains behind the existing install safety and backup behavior.
- The accepted LSTP-01F real-game validation included `install --dry-run`. This final v1.2.0 packaging audit did not perform a new real game install.

## Platform status / 平台狀態

- Windows 11: primary validated platform.
- Linux/Proton: pending real-platform validation.
- macOS: pending real-platform validation.

Cross-platform architecture does not imply acceptance on platforms that have not completed real-platform validation.

## Data and copyright boundary

BG3Loc does not ship Larian localization data, translated game text, or proprietary project corpora. Users generate localization and research evidence from their own game installation.
