# BG3Loc v1.1.0

BG3Loc v1.1.0 adds the public end-to-end translation workflow, reproducible research mapping, human review protocols, scoped translation projects, and release packaging hardening on top of the v1.0.0 localization core.

BG3Loc v1.1.0 在 v1.0.0 語言處理核心之上，新增公開端到端翻譯流程、可重現研究映射、人工審查協定、可控範圍翻譯專案，以及正式發布打包強化。

## Highlights / 重點功能

- Public high-level project/workflow CLI:
  `project init/check` and `workflow prepare/validate/rebuild/install/status`.
- Persistent schema-backed project configuration and workflow state.
- Evidence profiles: `basic`, `context`, `full`.
- Translation strategies: `standard`, `blind-first`.
- Explicit `ContentUid` project scope for controlled subset translation jobs.
- Translation package trust zones separating translator-facing delivery from internal evidence.
- Structural review protocols for Bark, Quest, UI/Skill, and Multilingual evidence.
- Project-language QA integration, including externally supplied Taiwan usage rules.
- Deterministic research scan/mapping support generated from the user's own BG3 installation.
- Clean-room documentation proving that a new user can bootstrap a scoped project without historical UID knowledge.
- Source-distribution hardening: release sdists now include public documentation and schemas.

## Compatibility / 相容性

This is a backward-compatible feature release over v1.0.0. Existing low-level Core commands remain supported.

The high-level workflow composes accepted Core behavior rather than replacing it.

## Installation / 安裝

Install the GitHub Release wheel:

```powershell
python -m pip install .\bg3loc-1.1.0-py3-none-any.whl
```

BG3Loc requires Python 3.11 or newer. Python 3.12 is the validated Windows baseline.

## LSLib prerequisite

BG3Loc does not bundle LSLib. LSLib 1.20.4 is the validated Windows archive-backend baseline.

Configure `Packed\Tools\Divine.exe` through `BG3LOC_DIVINE_EXE` as described in the archive backend documentation.

## Safety / 安全性

- `scan`, `extract`, `build`, workflow preparation, validation, and rebuild do not modify the game installation.
- High-level `workflow install` defaults to dry-run.
- A real high-level install requires explicit `--apply`.
- Scoped projects do not weaken validation; they redefine the legal project translation universe.
- `full + scope` remains fail-closed until structural-review surfaces become scope-aware.

## Platform status / 平台狀態

- Windows 11: validated Tier 1.
- Linux/Proton: pending real-platform validation.
- macOS: pending real-platform validation.

Cross-platform architecture does not imply acceptance on platforms that have not completed real-hardware validation.

## Data and copyright boundary

BG3Loc does not ship Larian localization data or translated game text. Users generate localization and research evidence from their own game installation.
